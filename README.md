# COMP 1510 Lab 08 - Arcade Score Keeper

Follow the lab handout (PDF) for the full requirements.

`arcade.py` is the program you complete. `plays.txt` is the paper log
it reads, and it creates `scores.json` when it saves the board.

`tests/test_lab08.py` ships with the given tests for the Parts 1 and
2 functions: run them, watch them fail against the stubs, and
implement each function until they pass. Leave the given tests as
they are. The Part 3 tests (`top_scores` and `plays_by_game`) are
yours to write first, in the marked section of the same file.

`main()` starts with one line that prints the header. Leave it alone.
You add your own lines in the final part.

Submit `arcade.py` and `test_lab08.py` to the Lab 8 dropbox in
Learning Hub before the deadline.
